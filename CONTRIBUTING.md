# Contribuer à RoadAlert

1. Toutes les modifications de code doivent passer par une Issue et une Pull Request (PR).
2. Assurez-vous que chaque PR est liée à une Issue existante.
3. Gardez les tickets petits et facilement réalisables.
4. Suivez les règles de style définies dans `.editorconfig` et les règles de linting du projet.
