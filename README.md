# ROADALERT

RoadAlert est une plateforme de signalement des anomalies routières.

## Architecture et Versions des Technologies

- `backend/`: API NestJS (v10.x) + Node.js (v18.x) + PostgreSQL (v15) + PostGIS (v3.3) + Docker.
- `frontend-mobile-citoyen/`: Application mobile Flutter (v3.x) pour les citoyens (iOS & Android).
- `frontend-mobile-agent/`: Application mobile Flutter (v3.x) pour les agents (iOS & Android).
- `frontend-admin-web/`: Application web Flutter (v3.x) pour l'administration (Web).
- `database/`: Scripts et migrations de base de données.
- `docs/`: Documentation du projet.
- `scripts/`: Scripts utilitaires.
