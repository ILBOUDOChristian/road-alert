# Politique de Sécurité

## Versions Supportées
Seule la dernière version du projet est activement maintenue et supportée pour les mises à jour de sécurité.

## Signaler une Vulnérabilité
Merci de ne pas signaler les failles de sécurité via les issues publiques de GitHub. Veuillez contacter directement l'équipe de sécurité par e-mail.
